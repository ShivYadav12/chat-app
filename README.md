# 💬 C++ Chat Application — Kubernetes + Docker Deployment

A **multi-user chat application** built in **C++** using **TCP sockets** and **multithreading**, fully containerized with **Docker** and deployed on **Kubernetes** for scalability and high availability.

---

## 🚀 Features

- Real-time multi-user chat using **TCP sockets**
- **Threaded server** for handling multiple clients simultaneously
- **Dockerized** for consistent builds across environments
- **Kubernetes deployment** for auto-scaling, self-healing, and easy management
- Simple **console-based client interface**
- Portable and lightweight

## 🧱 Technologies Used

| Tool | Purpose |
|------|----------|
| **C++** | Core programming language |

| **Docker** | Containerize the server and client |
